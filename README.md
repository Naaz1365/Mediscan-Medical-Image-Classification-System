# MediScan — Final Submission Project

## What is included
- `training/MediScan_Colab.py` — complete training/evaluation/Grad-CAM script
- `app/app.py` — Streamlit application
- `app/requirements.txt`
- `docs/Final_Report.md`
- `docs/Model_Card.md`

## Fastest way to finish
1. Open Google Colab.
2. Upload/run `training/MediScan_Colab.py` (GPU recommended).
3. Wait for training and evaluation to finish.
4. Download `mediscan_resnet50.pt` from `mediscan_outputs`.
5. Put it beside `app.py`.
6. Install requirements and run `streamlit run app.py`.
7. Capture screenshots for the report/PPT.
8. Use the actual metrics generated by the notebook.

## Important
Do not claim an accuracy value until the model has actually been trained and evaluated. Do not present this prototype as a clinical diagnostic system.
