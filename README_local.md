# MediScan — AI-Powered X-Ray Analysis System

MediScan is an AI-powered medical X-ray analysis prototype that uses deep learning and computer vision to analyze X-ray images and generate an AI-based prediction. The application provides an interactive Streamlit interface for uploading an X-ray image and viewing the predicted class and confidence score.

## Features

* Upload X-ray images through a simple web interface
* Deep learning-based X-ray classification
* ResNet50-based trained model
* Prediction with confidence score
* Grad-CAM support for model explainability
* Interactive Streamlit application
* Training and evaluation workflow using Google Colab

## How to Run

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
cd MediScan_FINAL_Submission/app
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Streamlit application

```bash
streamlit run app.py
```

The application will open in the browser.

### 4. Upload an X-ray

Upload a supported X-ray image through the application and click the prediction/analyze option to view the model output.

## Model

MediScan uses a ResNet50-based deep learning model trained for X-ray image classification. The trained model is stored as:

```text
mediscan_resnet50.pt
```

The training and evaluation workflow is provided in:

```text
training/MediScan_Colab.py
```

## Example Output

The application generates an output containing:

* Predicted class
* Confidence score
* Uploaded X-ray image
* Explainability visualization when available

## Disclaimer

MediScan is an educational and internship project prototype. Its predictions are generated by a machine-learning model and should not be considered a medical diagnosis or a substitute for evaluation by a qualified healthcare professional.
